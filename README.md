# Basic Virtual Piano

A basic virtual piano you can play in your browser.

## Run

Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Preview

If your environment says **"preview not found"**, open one of these directly:

- `index.html`
- `preview.html`

Or run the local server command above and visit:

- `http://localhost:8000/index.html`
- `http://localhost:8000/preview.html`

## Controls

- Click any piano key with your mouse.
- Or use keyboard keys: `A S D F G H J`.
