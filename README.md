# Basic Virtual Piano

A basic virtual piano you can play in your browser.

## How to preview this output

### Option 1 (quickest)
- Double-click `index.html` to open it directly in your browser.

### Option 2 (recommended local preview server)
Run:

```bash
./start_preview.sh
```

Then open either:
- `http://localhost:8000/index.html`
- `http://localhost:8000/preview.html`

You can also choose a custom port:

```bash
./start_preview.sh 9000
```


## Preview

If your environment says **"preview not found"**, open one of these directly:

- `index.html`
- `preview.html`

If you still see **"preview not found"**, use the local server URLs above explicitly.

## Controls

- Click any piano key with your mouse.
- Or use keyboard keys: `A S D F G H J`.
